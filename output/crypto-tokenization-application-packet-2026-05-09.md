## Sourceable Infrastructure Context: AtomicHub, WAXP, and Proof-of-Stake

Use this wording when the application or interviewer asks for technical context:

"The 2021 YoshiDrops / Yoshicoin Genesis Edition work sat in the WAX ecosystem, where AtomicHub/AtomicAssets was the practical NFT issuance and marketplace layer, and WAXP was the native utility token used across a delegated proof-of-stake blockchain. WAX's model was relevant because it was built for high-volume NFT/digital-item transactions, marketplace activity, staking, voting for block producers, and low-friction user onboarding."

Source-backed points:
- WAX is a blockchain built for NFTs, gaming, digital commerce, and marketplace-style applications. Current WAX materials describe 450M+ NFTs created, 15.3M+ blockchain accounts, and WAXP staking/voting for block producers.
- WAX uses delegated proof-of-stake (DPoS), where WAXP holders stake tokens for CPU/NET resources and vote for block producers who validate transactions and produce blocks.
- WAXP is the native token of WAX, used for NFT trades, staking rewards, governance/voting, and marketplace/dApp activity.
- AtomicAssets is the main NFT standard in WAX environments. Its smart contract supports actions such as mintasset, transfer, burnasset, setassetdata, and backasset.
- AtomicHub is an NFT marketplace built on WAX/AtomicAssets for creating, buying, selling, and collecting WAX-based NFTs.
